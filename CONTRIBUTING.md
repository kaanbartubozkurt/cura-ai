# Contributing to SightLab

Report bugs in GitHub issues. Include steps to reproduce, what you expected,
and what happened, with relevant screenshots or logs.

For questions, ideas and feedback, join the [SightLab Discord](https://discord.gg/bH2RqXWmjx).

Open pull requests against the `dev` branch.
Before pushing, run `ruff check` from `backend/` and `npm run lint` from `frontend/`.

Keep documentation current in the same PR, following the
[documentation guidance in CLAUDE.md](CLAUDE.md#keeping-documentation-current).
